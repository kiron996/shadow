# Shadow Website

The personal website and project hub for Shadow.

## Start locally

Open `index.html` in a browser, or use a local static server such as VS Code Live Server.

## Structure

- `css/` — shared visual system, responsive rules, and animations
- `js/` — navigation, project rendering, contact integration, and shared behaviour
- `pages/` — standalone portfolio pages
- `projects/` — individual Shadow project front ends
- `backend/` — future server-side services for Shadow AI and Shadow GK
